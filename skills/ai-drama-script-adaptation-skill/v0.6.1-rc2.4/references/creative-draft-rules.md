# Creative Draft Rules

Draft complete creator-facing Markdown scenes before JSON. The Markdown script must be directly readable as a drama script, not a Markdown expansion of schema fields.

Each scene containing a critical beat must actually dramatize:

```text
triggering event -> immediate character reaction -> action or dialogue progression -> emotional or relationship change -> new in-scene state
```

A scene body fails when it is only:

```text
two or three summary action sentences + a dialogue group + a concluding summary
```

Metadata can exist for JSON extraction and production indexing, but it must not dominate the creator-facing script. The creator-facing script should prioritize performable body text.

Recommended structure:

```text
Scene heading
Brief scene information
Script body
Action
Dialogue
Performance reactions
Sound or effective silence
Scene-end hook
```

Avoid repeating the same content as emotion labels, action summary, body action, and closing summary in the same scene. Repetition inflates validation surface without improving story body.

Preserve causal information when the source gives it. If the source explains why a character did or did not act, the reason must be in the script body, not only in metadata or coverage notes.
