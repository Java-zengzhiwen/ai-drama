# Source Conflict Policy

Run `source-claim-audit` before drafting. The audit checks claims about the same character, object, action, relationship, and causal chain across the source.

The audit output must include:

- `claims_examined`
- `potential_conflicts`
- `selected_interpretation`
- `resolution_basis`

When broad earlier narration and later concrete event detail differ, prefer the later explicit event sequence for drafting, but register the difference as a conflict or potential conflict.

Conflict detection cannot rely only on static validators. It must include semantic review of source claims before the first creative draft.
