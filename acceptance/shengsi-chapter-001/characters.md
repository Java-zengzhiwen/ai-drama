## 一、主角

### 沈清荷（姐姐·商道之刃）

#### 基本信息
- **身份**：沈家长女，商业掌舵人
- **年龄**：约二十岁（及笄之后，议亲阶段）
- **父亲**：已故（生前是商人，教沈清荷经商）
- **母亲**：未出场（人丁单薄的设定）

#### 外貌特征
- 手指常年握笔，指间有薄茧
- 书房窗外的桂花树是她的精神锚点

#### 性格层次

**表层（对外）**：
- 沉稳、话少、持重
- 渣男眼中："温柔、好哄、听话的未婚妻"

**中层（对内）**：
- 精于算计、冷静如棋手
- 凡事用账本说话
- 愤怒时不吼叫，在账本上记一笔

**深层（核心）**：
- 前世被利用至死，重生后的觉悟：爱情只是工具，财权才是根本
- 对妹妹的愧疚与保护欲并存
- 复仇不是情绪宣泄，是精心策划的商业战争

#### 核心能力
- 渠道掌控、资源调配
- 对数字和账目过目不忘
- 前世掌握盐铁渠道，这一世知道未来十年商业风向
- 训练有素的商业直觉

#### 标志性行为
| 动作 | 触发时机 | 在文中的应用 |
|------|---------|------------|
| 拨动算盘珠 | 重大决定前 | 第1章、第6章、第20章、第30章 |
| 在账本上记一笔 | 愤怒/记仇时 | 反复出现，贯穿全书 |
| 给妹妹夹菜 | 开心时 | 姐妹互动场景 |
| "这笔账，划不来" | 判断得失时 | 金句模式 |

#### 前世经历
- 被渣男利用商业才能，帮他平步青云登上户部高位
- 被渣男挑拨离间，以为妹妹要毒杀自己
- 临死前看到渣男搂着丞相之女林婉兮，亲口承认："我只是借你们沈家的钱袋子，铺我的青云路。"
- 被毒杀而死

#### 今世成长弧线

| 阶段 | 章节 | 状态 |
|------|------|------|
| 觉醒期 | 第1-3章 | 从震惊到清醒，与妹妹相认，确立复仇同盟 |
| 布局期 | 第4-10章 | 截胡生意、记账、设陷阱，表面演痴情未婚妻 |
| 发力期 | 第11-16章 | 改良制盐技术，开辟新渠道，蚕食渣男经济命脉 |
| 收网期 | 第17-20章 | 引导渣男入局，伪造投资人，准备证据 |
| 决裂期 | 第21-28章 | 送匿名信、当堂对质、撕婚书、烧婚约 |
| 终局 | 第29-30章 | 拿下皇商资格，掌管三个盐铺，成为独立女商人 |

#### 随身道具
- **算盘**（核心道具）：第1章结尾第一次拨动 → 第30章最后放下
- **账本**（秘密武器）：记录了渣男每一笔贪污、每一笔借款

### 沈清莲（妹妹·人心之网）

#### 基本信息
- **身份**：沈家次女，社交操盘手
- **年龄**：约十七八岁
- **训练经历**：十年"察言观色、撒娇卖痴"的训练（第2章自述）

#### 外貌特征
- 爱笑，笑容天真烂漫
- 随身携带梅花团扇，绣线已有些松了（暗示使用频率之高）

#### 性格层次

**表层（对外）**：
- 天真烂漫、笑语晏晏
- 渣男眼中："崇拜自己的小姨子，好利用"

**中层（对内）**：
- 通透机敏、话里藏刀
- 最擅长用无辜的语气说出最致命的信息
- 对姐姐真诚，对敌人演戏

**深层（核心）**：
- 前世痴迷渣男，被利用后惨死
- 重生后最痛的不是被渣男害死，而是前世与姐姐反目
- 她的复仇武器不是算盘，是人心

#### 核心能力
- 人际网络构建、情报收集
- 十年社交训练：记住每个人的生辰、软肋和欲望
- 前世广结善缘，掌握大量人脉情报
- 借力打力——不需要亲自出手，让敌人自相残杀

#### 标志性行为
| 动作 | 触发时机 | 在文中的应用 |
|------|---------|------------|
| 团扇掩住嘴角笑意 | 说完致命信息后 | 第3章、第7章、第22章 |
| 笑语晏晏，话里藏刀 | 社交场合 | 贯穿全书 |
| "哎呀，这可不巧了么" | 算计得逞时 | 金句模式 |
| 对姐姐真笑，对敌人假笑 | 角色切换时 | 社交场合与私下对比 |

#### 前世经历
- 被渣男甜言蜜语蒙蔽，前世与姐姐争风吃醋
- 四处炫耀未婚夫深情，结果同样被利用至死
- 重生方式：做了一场噩梦，梦中经历了前世的一切

#### 今世成长弧线

| 阶段 | 章节 | 状态 |
|------|------|------|
| 觉醒期 | 第1-3章 | 从噩梦中醒来，与姐姐对视即达成默契 |
| 布局期 | 第4-10章 | 扮演崇拜渣男的小姨子，散播假消息 |
| 发力期 | 第11-16章 | 社交策反，拉拢刘德旺，接触王夫人 |
| 收网期 | 第17-20章 | 安排假投资人方老板，信息误导渣男 |
| 决裂期 | 第21-28章 | 当面翻脸，公开揭露渣男真面目 |
| 终局 | 第29-30章 | 创办清莲书院，三顾茅庐请方先生，完成独立 |

#### 随身道具
- **团扇**（核心道具）：梅花绣纹，绣线已松，每次说完致命信息掩嘴笑
- **社交笔记**（暗线道具）：她能记住每个人的生辰、软肋和欲望

## 二、反派

### 顾长渊（渣男世子）

#### 基本信息
- **身份**：侯府世子（爵位继承人）
- **父亲**：老侯爷（仅侧面提及，第27章砸书房）
- **母亲**：侯夫人（仅侧面提及，第27章清理院子）
- **外表**：温润如玉，常穿月白色长衫
- **年龄**：约二十出头

#### 性格特征

**表面**：
- 温文尔雅，谦谦君子
- 谈吐风雅，举止得体
- 让人放下戒心的"好人"形象

**内核**：
- 极度自负，看不起商贾出身的沈家
- 精于算计，商品是"爱情"
- 核心信念："女人嘛，好哄"、"女人终究是女人"
- 贪婪且轻视女性——这是他致命的盲区

#### 前世经历
- 利用沈家姐妹的资源和感情，平步青云登上户部高位
- 挑拨离间让两姐妹互斗至死
- 最终搂着丞相之女林婉兮，亲口承认利用
- "我只是借你们沈家的钱袋子，铺我的青云路。"

#### 致命弱点
- 自负：至死不信女人能有翻天的智慧
- 贪婪：挪用公款、多线操作、越陷越深
- 轻视女性：即使"诸事不顺"，也不怀疑姐妹
- 真商人假君子：嘴上风雅，心里全是生意

#### 罪行清单（实际内容统计）
| 罪行 | 金额/内容 | 证据 |
|------|---------|------|
| 盐铺账目造假 | 近2000两 | 账本中"特定""杂项"条目 |
| 挪用户部公款 | 13000两 | 周书办被查获的私账 |
| 向沈家多次借款 | 7000+两 | 借据（沈清荷保管） |
| 虚假投资人协议 | 2000两 | 合伙契书（沈清荷保留） |
| 抬高盐铺采购价中饱私囊 | 数额不明 | 赵四提供的证据 |

#### 人物弧线（权力下坠曲线）

| 章节 | 状态 | 关键事件 |
|------|------|---------|
| 第1-3章 | 志得意满 | 两个女人为我争风吃醋，一切尽在掌握 |
| 第4-9章 | 隐隐不安 | 南货被截、传言四起，但归因于运气不好 |
| 第10章 | 信心巅峰 | 拿下漕运资格，以为大计将成 |
| 第13章 | 开始怀疑 | 派人调查，被姐妹完美伪装骗过 |
| 第16-17章 | 焦虑加深 | 盐铺收入下降、粮商催款 |
| 第18-19章 | 假装镇定 | 查账通过、投资到位，又放心了 |
| 第20章 | 恍然大悟 | 三个关键人物同时消失，但不敢信是沈清荷 |
| 第21-23章 | 疯狂补救 | 四处借钱被拒、周书办被抓、龙井茶出现在书房 |
| 第24章 | 真相大白 | 姐妹当面对质，揭露一切 |
| 第25章 | 彻底崩溃 | 公堂定罪、林婉兮冷眼、锒铛入狱 |
| 第26-27章 | 无力挣扎 | 反咬失败、削爵、发配北疆 |
| 第28章 | 彻底出局 | 婚约被撕毁、侯府试图挽回被拒 |

#### 创作铁律
- ✅ 聪明但自负——他不是蠢，是看不起女人
- ✅ 在中期之前（第13-19章）察觉有"幕后黑手"但不信是姐妹
- ✅ 不洗白——没有"深情无奈"的戏码
- ✅ 结局：人财两空，身败名裂，发配边疆

## 三、核心盟友

### 赵四（第一个内线）

- **身份**：侯府盐铺二掌柜
- **年龄**：约三十岁
- **工龄**：为侯府工作六年
- **性格**：老实本分、不善交际、孝顺
- **家庭**：母亲常年咳疾，需要定期抓药；妹妹在绣坊做学徒
- **住址**：侯府西边巷子第三家，门口有棵槐树
- **被策反方式**：沈清莲亲自登门，承诺沈家铺子的职位、双倍月钱、让他照顾母亲
- **作用**：
  - 提供盐铺真实账目（揭露顾长渊抬高采购价中饱私囊）
  - 向顾长渊提供假情报（雪盐日产量只有200斤，实际500斤）
  - 成为姐妹在侯府内部的眼线
- **出场**：第8章（策反）、第16章（提供假情报）

### 陈伯远（制盐伙伴）

- **身份**：盐匠，手艺人
- **性格**：老实、技术好但不善经营
- **地点**：原作坊在城外东边五六里，后迁至城东运河边
- **技术**：只会做灰盐（低价）
- **被提升方式**：沈清荷带着"豆浆法"找上门——卤水中加豆浆去除杂质，产出纯白如雪的"雪盐"
- **合作关系**：沈清荷提供资金和销路，陈伯远提供技术，五五分账
- **发展轨迹**：
  - 第11章：小作坊，几口锅
  - 第14章：六口大锅，日产500斤
  - 第29章：八口锅→二十口锅，供应官盐
- **出场**：第11章、第14章、第29章

### 刘德旺（粮商盟友）

- **身份**：京城粮商
- **资历**：与侯府合作八年
- **性格**：稳重、话少、守信、讲义气
- **与渣男关系**：顾长渊欠他1800两粮款未还，早已不满
- **被策反方式**：沈清莲在赏春宴上主动接触，暗示沈家更可靠
- **策反条件**：沈家所有粮食业务过他的手，市价交易，不拖欠货款
- **额外作用**：成为姐妹监控渣男动向的暗线
- **出场**：第12章（初次接触）、第15章（正式入伙）

### 方先生（书院教师）

- **身份**：女性学者，曾在江南书院任教，退休回京
- **出场**：第29章（沈清莲三顾茅庐，第三次带自酿桂花酒才请动）
- **作用**：清莲书院第一位先生，象征沈清莲的事业独立
