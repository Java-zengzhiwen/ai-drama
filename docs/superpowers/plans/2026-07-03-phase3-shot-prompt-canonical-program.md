## Program Gate

Each child plan must pass these gates before implementation:

- human review marks the child plan approved;
- implementation authorization is recorded for that child plan;
- mechanical audit confirms no future dependencies inside the child plan;
- repository evidence is re-read against the current branch.

Each child implementation must pass these gates before the next child plan may be authorized:

- focused tests;
- full `python3 -m pytest -q`;
- child verification report;
- commit containing only the child implementation allowlist.
