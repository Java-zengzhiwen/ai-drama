These tokens describe the selected direction and can later be translated to Ant Design theme tokens.


Cards should not be nested. Major work surfaces use dividers and subtle background changes before elevation.

## Components

- Tables use stable row height and sticky header behavior.
- Primary buttons are used only for confirm or create actions.
- Status chips are compact text labels with colored dots or light fills.
- Blocked messages are inline callouts near the disabled action.
- Inspectors use form rows with labels above fields for scan speed.
